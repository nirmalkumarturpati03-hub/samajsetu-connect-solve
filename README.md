# SamajSetu: Connect & Solve

You are a senior full-stack engineer, AI architect, UX designer, product designer and government-tech systems architect.

Build a production-quality responsive web application called:

SAMAJSETU

Tagline:

"Connecting Community Problems with Collaborative Solutions"

Problem Statement:

Smart India Hackathon 2026 — SIH26043

Government of Jharkhand

CORE VISION

SamajSetu is NOT a generic complaint or grievance portal.

It is an AI-powered community innovation platform that converts real-world societal problems into validated innovation projects by connecting:

Citizens

→ Government

→ Universities

→ Faculty

→ Students

→ Startups

→ MSMEs

→ Industries

→ CSR organizations

→ Research institutions

The complete journey is:

Community Problem

→ AI Understanding

→ Problem DNA

→ Duplicate Detection

→ Verification

→ Impact/Priority Score

→ University Matching

→ Faculty + Student Team Formation

→ Industry/CSR Matching

→ Project Creation

→ Prototype

→ Pilot

→ Community Feedback

→ Impact Measurement

→ Government Analytics

→ Scale Up

The application should make this workflow extremely clear visually.
